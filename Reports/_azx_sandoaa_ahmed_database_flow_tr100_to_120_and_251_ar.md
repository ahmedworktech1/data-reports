## 2. تدفق البيانات عند `tr_ty = 100` (طلب احتياج)

```
  ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
  │ AZTRH    │────▶│ AZTRD    │────▶│ AZITMS   │────▶│ AZLOCS   │
  │ (الرأس)  │     │ (التفاصيل)│     │ (الصنف)  │     │ (المخزن)  │
  └──────────┘     └──────────┘     └──────────┘     └──────────┘
       │                 │                 │                 │
       └─────────────────┼─────────────────┘                 │
                         ▼                                   ▼
                    AZTRTY (وصف الحركة)   ←  الاتصال المركب (LOC, TR_TY, TR_NO)
```

**ماذا تعرض التقارير؟**
- رقم الحركة (`TR_TY`, `TR_NO`)
- اسم الحركة (`Dscr_AR`)
- رقم الصنف (`ITM_CD`)، الكمية (`QTY`)، السعر (`PKPRC`)
- المخزن (`LOC`)، التاريخ (`TR_DT`)، اسم الحساب (`Acc_No`)

## 3. تدفق البيانات عند `tr_ty = 120` (عمليات الموردين)

```
  ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
  │ AZTRH    │────▶│ AZTRD    │────▶│ AZACCMF  │────▶│ AZTRTY   │
  │ (الرأس)  │     │ (التفاصيل)│     │ (الحساب) │     │ (النوع)  │
  └──────────┘     └──────────┘     └──────────┘     └──────────┘
       │                 │                 │                 │
       └─────────────────┼─────────────────┘                 │
                         ▼                                   ▼
                    DLVRLOC (مكان التسليم)      WHERE AZACCMF.Stpd = '1'
```

**ماذا تعرض التقارير؟**
- `acc_no`، `acc_nm` (رقم الحساب واسم الشركة)
- `FNCL_TR_NO` (رقم المستند المالي)
- `TR_DT` (التاريخ)
- `TOT_MIN_HDISC` (إجمالي الخصم)، `LTOT` (إجمالي المبلغ)
- `DLVR_LOC` + وصفه من `DLVRLOC`
- مجموعة الحساب: `SUM(qty)`، `AVG(price)`، `SUM(qty × price)`
- كلّ حركة مقيّدة بـ `AZACCMF.Stpd = '1'`

## 4. تدفق البيانات عند `tr_ty = 251` (إدارة / طلب)

```
  ┌──────────┐     ┌──────────┐     ┌──────────────┐     ┌──────────┐
  │ AZTRH    │────▶│ RequestInstanceLogs │────▶│ Transitions  │────▶│ States   │
  │ (الرأس)  │     │ (سجلات الفحص)      │     │ (انتقال)    │     │ (الحالة) │
  └──────────┘     └──────────┘     └──────────────┘     └──────────┘
       │                                          │
       └──────────────────────────────────────────┼──┘
                                                  │
                                                  ▼
                                          ┌──────────┐
                                          │ BrcaUsers│
                                          │ (المستخدم)│
                                          └──────────┘
```

**ماذا تعرض التقارير؟**
- `Id` (رقم السجل)
- `TransitionDate` (تاريخ الانتقال)
- `Reason` (السبب)
- `TriggerName` (مفتاح الإغلاق)
- `FromStateName`، `ToStateName` (الحالة من وحيد)
- اسمّ المستخدم المعني

## 6. الخلاصة

| `tr_ty` | النوع              | التقارير الرئيسية                        | الجداول المستخدمة                          |
|---------|--------------------|------------------------------------------|---------------------------------------------|
| 100     | طلب احتياج         | `Aztrh100.trdx`                          | AZTRH، AZTRD، AZITMS، AZLOCS، AZTRTY        |
| 101–110 | فلاتر تعديل الكمية | `AZUSRJBSD`                              | جدول المؤقت `AZUSRJBSD`                     |
| 120     | عمليات الموردين     | `purchase_*.trdx` (مجموعة)               | AZTRH، AZTRD، AZACCMF، AZTRTY، DLVRLOC      |
| 251     | إدارة / طلب         | `Purchase_AztrhRequestInstanceLogss.trdx`| AZTRH، Workflow، Transitions، States، Users |
```
